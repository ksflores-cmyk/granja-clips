# Política de privacidad — Guion Vivo subidas

*Última actualización: 27 de noviembre de 2026.* · [English below](#privacy-policy--guion-vivo-subidas)

«Guion Vivo subidas» es la automatización con la que el canal de YouTube **Guion Vivo** sube sus propios videos.
No es una app pública: sólo la usa el dueño del canal.

- **Qué datos usa:** sólo el permiso para subir y administrar videos del propio canal de Guion Vivo
  (`youtube.upload` y `youtube.force-ssl`). No lee datos de otros usuarios ni de otros canales.
- **Dónde se guarda:** el token de acceso vive como secreto cifrado en GitHub Actions del repositorio
  `granja-clips`. Nunca se publica ni se comparte.
- **Con quién se comparte:** con nadie. No se venden ni se ceden datos.
- **Cómo revocarlo:** en https://myaccount.google.com/permissions, quitando el acceso a «Guion Vivo subidas».
- **Contacto:** guionvivo.clips@gmail.com

# Privacy policy — Guion Vivo subidas

*Last updated: November 27, 2026.*

"Guion Vivo subidas" is the automation the **Guion Vivo** YouTube channel uses to upload its own videos. It is not a
public app: only the channel owner uses it.

- **Data used:** only the permission to upload and manage videos on the Guion Vivo channel itself (`youtube.upload`
  and `youtube.force-ssl`). It does not read data from other users or channels.
- **Storage:** the access token is stored as an encrypted GitHub Actions secret in the `granja-clips` repository. It
  is never published or shared.
- **Sharing:** none. No data is sold or transferred.
- **Revoking access:** at https://myaccount.google.com/permissions, remove "Guion Vivo subidas".
- **Contact:** guionvivo.clips@gmail.com
